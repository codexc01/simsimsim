# 📱 Ucell Number Monitor Bot

Лёгкий, асинхронный Telegram-бот на Python 3.12+ для круглосуточного (24/7) мониторинга доступных красивых номеров оператора **Ucell**.

---

## ⚡ Особенности

- 🚀 **Максимально лёгкий**: Использует прямой асинхронный HTTP API Ucell без Selenium/Playwright и тяжелых браузеров.
- 👥 **Мультипользовательский режим**: Каждый пользователь может свободно пользоваться ботом и настраивать свои фильтры категорий и шаблонов.
- 🎯 **Интеллектуальный поиск по структуре**: Распознавание сложных шаблонов типа `XXX AA XX`, `AB AB AB`, `ABC ABC`, `ABCCBA`, `AAA AAA` и др.
- 🔮 **Автоматические правила**: Определение палиндромов (зеркальных комбинаций), последовательностей (`1234`, `9876`), комбинаций `000`, `777`, `1111` и 4 одинаковых цифр.
- 💎 **Динамические категории**: Выбор категорий номеров (Simple, Steel, Bronze, Silver, Gold, Platinum, Vip, Lux и др.).
- 💾 **SQLite (aiosqlite)**: Индивидуальное отслеживание дубликатов для каждого пользователя с возможностью повторных уведомлений при перепоявлении номера.
- ⚙️ **Гибкое управление**: Поддержка добавления собственных шаблонов прямо из чата Telegram.

## 🛠 Установка и запуск

### 1. Клонирование / Переход в папку проекта

```bash
cd ucell_monitor
```

### 2. Создание и активация виртуального окружения

```bash
python3 -m venv venv
```

**Windows:**
```cmd
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Настройка конфигурации `.env`

Cкопируйте `.env.example` в `.env`:

```bash
cp .env.example .env
```

Отредактируйте файл `.env`:
```env
BOT_TOKEN=123456789:ваш_токен_бота
CHECK_INTERVAL=120
```

### 5. Запуск unit-тестов (опционально)

```bash
PYTHONPATH=. python3 tests/test_filters.py
```

### 6. Запуск бота

```bash
python bot.py
```
